// how it works & privacy

🔒 Values are opaque to Claude. They're written straight into _secrets/cookies/*.txt and _secrets/api_keys.json — both git-ignored. The dashboard only ever reports presence (a file exists, a key is non-empty) and a byte count, never the contents. The save log records the source + size, not the value.

Runner decides who may act on a secret. local = the local AI uses it autonomously and privately (DLsite, YouTube, asmr.one). claude = you hand it over per-task. manual = browser/extension only.

Gentle is the minimum delay (seconds) between requests, so a membership account is never rate-limit flagged.

Cookies are taken from your browser with an extension (e.g. Get cookies.txt / Video DownloadHelper) in Netscape format and pasted or file-loaded here. API keys (e.g. SauceNAO for reverse-image VTuber ID) go in the key tab.
